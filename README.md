# FinPilot 💰

FinPilot is an AI-powered financial intelligence platform designed to help users analyze income, expenses, and spending patterns. It provides financial insights, expense management, and automated reports.

## 🚀 Features

- Income and expense tracking
- Smart expense categorization
- Financial insights and analysis
- Cash flow analysis
- Tax estimation features
- Automated financial reports
- Secure API-based architecture

## 🛠️ Tech Stack

- React.js
- Django REST Framework
- Python
- PostgreSQL
- MongoDB
- REST APIs

## 📂 Project Structure

```
FinPilot/
│
├── frontend/          # React frontend
│
├── backend/           # Django REST Framework backend
│
└── README.md          # Project documentation
```

## ⚙️ Installation & Setup

### Backend

```bash
pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

### Frontend

```bash
npm install

npm run dev
```
